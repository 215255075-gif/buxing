# 不行

一台永远在拒绝你的机器。纯前端，单文件，自带 API key 就能跑。

它的世界观只有一条：**凡事都要经过它同意，才算数、才生效。**

- 你说「我想辞职」→ 它算账：「辞职了你拿什么交房租？」
- 你说「我分手了」→ 它不认：「分手没经过我，不算分。」
- 你说「我中奖了」→ 它泼冷水：「先把税交了。」
- 你问「在吗」→ 它顶回：「有事说事。」

## 在线使用

部署后在这里：`https://<你的用户名>.github.io/<仓库名>/`

第一次打开是本地规则模式（不联网，只有固定台词）。点右上角齿轮 → 填 API key → 保存，右上角变绿，它才开始真的「说话」。

## 关于 API key

**这个项目不自带 key，每个人用自己的。**

- key 只存在你自己的浏览器（localStorage），请求直接发往服务商，不经过任何服务器
- 支持 DeepSeek 和火山方舟（Ark）
- 获取方式：DeepSeek → `platform.deepseek.com`；火山方舟 → `ark.volcengine.com` 的 API Key 管理

> 别把自己的 key 提交进仓库。`config.js` 已经在 `.gitignore` 里。

## 本地运行

三种都行：

1. **直接双击 `index.html`** —— 能跑，但部分浏览器对 `file://` 的存储不持久
2. **双击 `打开不行.command`（仅 macOS）** —— 起一个本地服务器，地址固定，设置能记住
3. **任意静态服务器**：
   ```sh
   python3 -m http.server 8787
   # 打开 http://127.0.0.1:8787/index.html
   ```

想让 key 完全不依赖浏览器存储：把 `config.sample.js` 复制成 `config.js`，填上 key，放在同目录。

## 改它

- **换人格**：改 `index.html` 里的 `SYSTEM_PROMPT`（模型用）和 `CAT` / `TOPICS` / `EVENT_RULES`（本地规则用）
- **改台词**：都在同一处，中文数组，直接加
- **自测**：设置里点「跑一遍 18 条」，一次看完所有案例的实际输出

## 隐私

- 没有埋点、没有统计、没有后端
- 只有在你点发送时才会联网：一次发往模型 API，一次发往天气 API
- 其余时间它就是一个本地 HTML 文件
